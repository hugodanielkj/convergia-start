# Decisões (a partir de D-24)

Um arquivo por decisão, para duas pessoas não editarem o mesmo arquivo: `AAAA-MM-DD-<trilha>-<slug>.md` (ex.: `2026-11-20-b-feriados-estaduais.md`).

Modelo:

```md
# <Título>

- **Data / trilha:** 2026-11-20 / B
- **Decisão:** o que foi decidido.
- **Motivo:** por quê, em 1–3 linhas.
- **Substitui:** D-xx ou arquivo anterior (se houver).
```

Decisões D-01 a D-24 estão em `../decisoes.md`.
